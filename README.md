# Wahoo-Game
A browser-based version of the classic Wahoo board game.Players can play against AI opponents or other players online.

Features
Play Wahoo directly in the browser
Play against AI opponents
Multiplayer support
Interactive digital game board
Legal move and game-rule validation
Responsive design for desktop and mobile
Simple, clean user interface
Technologies
HTML
CSS
JavaScript

Additional technologies may be added later to support online multiplayer and other features.

Project Status

🚧 In Development

The initial focus is building the core Wahoo game and gameplay experience. AI and online multiplayer will be developed as the project progresses.
